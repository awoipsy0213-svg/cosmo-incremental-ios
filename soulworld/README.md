# 魂の世界｜スマホ横画面・3D自律育成試作 Ver.0.1.0

《理》とは別プロジェクト。3D WebGL・JavaScript・CSSで構成する、依存ライブラリ不要のブラウザ試作です。WebGL非対応環境ではCanvas2Dの簡易見た目で動作します。

## 起動

- GitHub Pages: リポジトリ直下から公開している場合、`https://<username>.github.io/<repo>/soulworld/`
- PCローカル: `python -m http.server 8080` を公開ディレクトリで起動し、`http://localhost:8080/soulworld/`
- iPhone: Safariで開き、横向きで操作。`共有 → ホーム画面に追加` でPWAとして追加可能（公開URLはHTTPSが必要）

## 動作する機能

- WebGL実3D（外部ライブラリ/CDN不要）：共通のメイン・サブ素体、自然な待機・歩行・作業・成功・交流反応
- 5×5拠点、メインタウン・英雄の家・菜園・木・石、サブ5枠、5秒逐次生成
- サブ自律行動：採集、建築予約・進行、農業、訓練、食料・資材の上限
- 300秒寿命、溺死/溶岩/襲撃、魂が神殿へ蓄積、手動回収で共有熟練度へ反映
- 拠点活動時間3分ごとの動物襲撃、15分ごとのゴミ撤去（試験用）
- 右下の指示コントローラー、担当人数配分、視点ドラッグ、拡大縮小、選択、追尾、可愛がる
- 簡易探索、キャラバン容量、簡易PvE、最初のクリアでボウガン設計図
- localStorage自動保存、独立保存キー、JSON書き出し/復元、オフライン10時間上限の試験ジェム
- PWA/Service Worker：初回取得後のブラウザ再訪に対応
- 設定の検証速度 ×5/×20（開発試験専用）

## 保存とデータ分離

- 保存キー: `soul_world_browser_proto_v001`
- 他作品《理》の `cosmo_incremental_v01` / `kotowari_v31_normal` は読み書きしません。
- バックアップ: 設定 → JSONを書き出し。長期に同じブラウザのlocalStorageだけに依存しないでください。
- サービスワーカーは `/soulworld/` 内だけを管理します。既存のルートアプリ用の `sw.js` を変更しません。
