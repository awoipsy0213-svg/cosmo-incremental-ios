# 《理（ことわり）》Ver.3.3 — LIVE 購入UI・仮バランス検証版

このリポジトリの**ルート直下 `index.html`** が、GitHub Pagesで公開されるブラウザ/PWA版です。
`www` は過去のCapacitor iOSビルド用で、今回更新しません。

## Ver.3.3の主な変更

- **購入表示をライブ更新**：資源所持数・必要額・購入可否・MAX購入数を表示中のボタンに軽量反映。今までの最大約1.5秒遅延をなくす。
- **購入支援**：不足額・目安時間・達成率・購入可能数・生成量（仮）を表示。
- **表示フィルタ**：「購入可能のみ」をON/OFF。データは変えない。
- **手動長押し**：押している間だけ連続購入。自動購入機能やマクロの解放ではない。
- **設定**：購入ヒント、フィルタ、長押しをON/OFFできる。
- **暫定の生産係数**：源の1Lvあたり0.02→0.4。正式な仕様にはせず `balance-config.mjs` に集約。
- **PWA**：新規ファイル `live-ui.css`・`purchase-insights.mjs` をバージョン3.3.0としてキャッシュ。

## 更新と保存

GitHub Pagesへ`main`をコミットすると公開処理が開始されます。起動中の旧版が「保存して更新」を表示した場合は、まずバックアップを取り、ボタンを押してください。Safariサイトデータを削除しないでください。

※ GitHubのリポジトリに書き込むだけで、Codemagic iOSビルド済みアプリのバイナリは自動更新されません。今回の対象はブラウザ/PWA版です。
