## Ver.3.6 の変更

《源》30種の秒間生産量と購入費用を調整しました。源1〜6は `0.1 / 0.5 / 1 / 5 / 25 / 100 オーブ/秒/Lv`。源7以降は4倍ずつ。初回価格は源1〜6が `30 / 120 / 300 / 1500 / 7500 / 30000 オーブ` で、源7以降は4倍ずつ。**各源のレベルを1段階上げるたび次の費用が1.35倍**になります。価格は暫定であり、段階上限・節目・固有効果は変更していません。

- 調整場所：`balance-config.mjs` の `provisional.source.perSecondPerLevel`, `baseCosts`, `costGrowth`。
- 源カードに1Lvあたりの生産量を表示し、購入ボタン近くの生成増分も同じ数値を使います。
- 旧セーブのLvは引き継がれますが、**同じLvの生産量・今後の購入価格は更新後の値になります**。
- 背景の水色×紫の発光、BOOST、通常と検証セーブの分離は維持。
- [BALANCE_V36.md](./BALANCE_V36.md) に30種の一覧・価格例・リスク、[TEST_REPORT_V36.md](./TEST_REPORT_V36.md) に検証結果を記載。

## データ保護・確定仕様との区別

- 未決定は資料どおり **「？？？」/ `null`**。試案は**未採用**、上記試験は設計上の正式決定ではありません。

- 資源受領A/B、破壊と崩壊の区別、7つの惑星効果の最終採用、《刻印》の自動化や《源》の正式7効果は**引き続き要確認**。

## iPhoneで候補を試す

1. [ゲーム本編](https://awoipsy0213-svg.github.io/cosmo-incremental-ios/) で **`3.5 · RESEARCH`** 表示を確認。
2. 右上の≡（ORGANIZER）から **「研究・試案」** を開く。
3. 「**別セーブで研究候補を確認・試用する**」を選び、URL末尾 `?lab=1` の検証モードへ。
4. 検証画面の「**候補効果を検証開始**」を押す。
5. 研究項目を見るか、検証操作から惑星・資源を用意して投入する。検証データは通常セーブに反映されません。
6. 再び通常プレイへ戻る場合は `?lab=1` を除いた元のURLを開く。

**Safariサイトデータ・旧セーブは削除しないでください。** お使いの端末の保存に依存するため、更新前にJSONを書き出すことを推奨します。
