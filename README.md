# 《理（ことわり）》Ver.3.4 — STABLE UI / BOOSTショートカット版

このリポジトリの**ルート直下 `index.html`** が、GitHub Pagesで公開されるブラウザ/PWA版です。
`www` は過去のCapacitor iOSビルド用で、今回更新しません。

## Ver.3.4の主な変更

- **安定したレイアウト**：購入ボタン・価格・進行ヒント・購入状況欄の表示領域を固定。所持額や必要コストの桁が変わってもカードとタブの位置が飛び跳ねないようにした。数値は引き続きリアルタイム更新。
- **左端の⚡BOOSTショートカット**：ステージバー左端で加速ON/OFF。BOOSTが空なら同じボタンから詳細画面へ。加速中は青紫に光り、残量を示す細いバーを表示。全画面パネル中も操作可能。
- **動的DOMの安定化**：購入金額の書き換え時にボタン全体を再生成せず、数値テキストだけを更新。
- **BOOST画面のリアルタイム表示**：残量・状態・ゲージ・開始/停止ボタンを画面更新ごとに直接同期。
- **既存データを維持**：セーブキー、スキーマ31、BOOSTの計算・試験倍率、ゲーム効果、惑星未決定仕様に変更なし。

## Ver.3.3の主な変更（継続）

- **購入表示をライブ更新**：資源所持数・必要額・購入可否・MAX購入数を表示中のボタンに軽量反映。今までの最大約1.5秒遅延をなくす。
- **購入支援**：不足額・目安時間・達成率・購入可能数・生成量（仮）を表示。
- **表示フィルタ**：「購入可能のみ」をON/OFF。データは変えない。
- **手動長押し**：押している間だけ連続購入。自動購入機能やマクロの解放ではない。
- **設定**：購入ヒント、フィルタ、長押しをON/OFFできる。
- **暫定の生産係数**：源の1Lvあたり0.02→0.4。正式な仕様にはせず `balance-config.mjs` に集約。
- **PWA**：新規ファイル `live-ui.css`・`purchase-insights.mjs` をバージョン3.4.0としてキャッシュ。

## 更新と保存

GitHub Pagesへ`main`をコミットすると公開処理が開始されます。起動中の旧版が「保存して更新」を表示した場合は、まずバックアップを取り、ボタンを押してください。Safariサイトデータを削除しないでください。
